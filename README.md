# Apna eMitra (apnaemitra.in)

Apna eMitra is an independent Hindi-first jobs and digital assistance portal for small towns and rural youth across India. It shares verified government/private job information, admit cards, results, government schemes, document guidance, and study resources.

## Architecture & Tech Stack
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (Hosted on GitHub Pages)
* **Backend & Database:** Supabase (PostgreSQL, Authentication, and Storage)
* **Job Discovery Automation:** GitHub Actions & Python (`scripts/`)
* **Domain:** `https://apnaemitra.in`
